# Storyphilium-CNPHLM-family

```markdown
# 📖 Storyphilium — Профессиональный сценарный редактор

**Storyphilium** — это одностраничное веб-приложение (SPA) для профессиональных сценаристов, которое объединяет мощный текстовый редактор с интеллектуальными инструментами анализа и структурирования сценария. Всё работает в браузере, без регистрации и серверов — данные хранятся локально в `localStorage`.

Проект является частью экосистемы сервисов для сценаристов и кинопрофессионалов, создаваемых в рамках **Cinephilium**. 

> **🔗 Подписывайтесь на Telegram-канал:** [@t.me/Cinephilium](https://t.me/Cinephilium)

## 🎯 Ключевые возможности

| Возможность | Описание |
|-------------|----------|
| **📚 Библиотека проектов** | Карточки с названием, жанром, датой изменения и количеством страниц. Корзина с возможностью восстановления. |
| **📝 Трёхпанельный редактор** | Навигация по сценам (слева) → текстовый редактор с автосохранением (центр) → персонажи и заметки (справа). |
| **🎭 Подсветка диалогов** | Строки в формате «ИМЯ: текст» автоматически подсвечиваются цветом персонажа из пастельной палитры (20 цветов). |
| **🧑‍🎤 Управление персонажами** | Автоматический сбор всех персонажей по шаблону «ИМЯ:». Клик по имени → подсветка всех его диалогов жёлтым фоном. |
| **📌 Заметки к тексту** | Выделите фрагмент → добавьте заметку. Клик по заметке → прокрутка к месту в редакторе. |
| **🔄 Перетаскивание сцен** | Изменение порядка сцен перетаскиванием (SortableJS) — в левой панели и в режиме «Структура». |
| **📊 Режим «Структура»** | Карточки сцен с заголовками и превью. Перетаскивание = перестроение всего сценария. |
| **🌙 Режим «Тихий ритм»** | Полноэкранный режим для чтения. Тёплый кремовый фон, увеличенный шрифт, плавный скролл. Выход по `Esc`. |
| **📤 Экспорт** | TXT, DOCX, PDF, JSON (резервная копия всех проектов). Восстановление из JSON с подтверждением. |
| **📈 Статистика** | Общее количество страниц, персонажей, самый продуктивный день, график активности за 7 дней (Chart.js). |
| **⚡ Горячие клавиши** | `Ctrl+S` — сохранение, `Tab` — 4 пробела, `Ctrl+Z` / `Ctrl+Y` — отмена/повтор. |

## 🎨 Дизайн-система

- **Тёмная премиум-тема** — фон `#151515`, панели `#1e1e1e` с размытием, текст `#e8e6e3`.
- **Акценты** — оранжево-красный `#ff6b35` и золотой `#f5a623`.
- **Шрифты** — Inter (интерфейс) + PT Mono (моноширинный редактор).
- **Анимации** — плавное появление панелей, ховеры с увеличением и свечением.
- **Адаптивность** — минимальная ширина 1024px, на узких экранах правая панель сворачивается.

### 🎯 Концепция экосистемы

Все проекты Cinephilium строятся на трёх принципах:

| Принцип | Описание |
|---------|----------|
| **Простота** | Минимум настроек, интуитивный интерфейс, фокус на задачу. |
| **Локальность** | Данные остаются у пользователя. Никаких серверов, регистраций и платных подписок (если не требуется облачная синхронизация). |
| **Единый язык** | Все инструменты используют общие термины, структуры и подходы. Переход между проектами не требует переобучения. |

### 🔗 Взаимосвязь проектов

Экосистема устроена так, чтобы проекты дополняли друг друга:

```
[Идея] → Storyphilium (написание сценария) → Screenphilium (раскадровка) → 
Castphilium (кастинг) → Audiphilium (звук) → Cinephilium (анализ готового фильма)
```

Каждый следующий проект использует данные предыдущего, но остаётся полностью независимым. Например, из **Storyphilium** можно экспортировать сценарий и загрузить его в **Screenphilium** для визуализации — без потери данных и без необходимости вводить всё заново.

### 🧠 Кто создаёт экосистему

Все проекты разрабатываются независимым энтузиастом, который 2+ лет изучает киноиндустрию и сценарное мастерство.

Мотивация простая: создать набор инструментов, которых не хватает русскоязычным сценаристам и кинематографистам, и сделать их доступными каждому.

**Весь код** публикуется в открытом доступе, с документацией и примерами использования. Каждый может не только использовать инструменты, но и дорабатывать их под свои задачи.
