## ⚡ Основные возможности (честный список)

| Фича | Работает? | Нюансы |
|------|-----------|--------|
| Создание и переключение проектов | ✅ Да | Хранятся в `localStorage` — не потеряются, пока не очистишь кэш |
| Автосохранение (каждую секунду после паузы) | ✅ Да | Если закроешь вкладку — текст сохранится |
| История изменений (`Ctrl+Z` / `Ctrl+Y`) | ✅ Да | До 60 шагов — хватит, чтобы откатить случайное удаление |
| Статистика (символы, слова, строки, страницы, сцены, персонажи) | ✅ Да | Страницы считаются из расчёта ~1000 символов — условно, но для черновика норм |
| Поиск и замена (`Ctrl+H`) | ✅ Да | Без регулярных выражений, но основное делает |
| **Экспорт** | ⚠️ Частично | **TXT, Fountain, JSON** — работают везде. **PDF** и **HTML** — пока только в **Google Chrome** (на Firefox и Safari могут быть артефакты) |
| Навигация по сценам и персонажам (сайдбар) | ✅ Да | Сцены определяются по заголовкам `НАР./ИНТ./ЭКСТ.`; персонажи — по капсу (заглавные строки). Если стиль нестандартный — навигация может ошибаться |
| Фокус-режим (`Ctrl+F`) | ✅ Да | Прячет всё, кроме текста — помогает не отвлекаться |
| Темы оформления (5 штук) | ✅ Да | От «Космоса» до «Neural White» — переключение через `Ctrl+T` |
| Таймер сессии | ✅ Да | Считает время работы над проектом — сбрасывается при обновлении страницы |
| Горячие клавиши | ✅ Да | Полный список — см. ниже |
| Адаптивность | ✅ Да | На телефонах интерфейс сжимается, но работать можно |
| Печать/PDF | ⚠️ Только Chrome | Используется стандартное окно печати браузера. На Chrome — красиво, на других — как повезёт |

## ⚠️ Что пока НЕ работает (и, возможно, не заработает в ближайшее время)

- **Облачное хранение** — нет, данные только на твоём устройстве.
- **Импорт** — только экспорт. Загрузить готовый сценарий из файла пока нельзя (только копировать текст руками).
- **Проверка орфографии** — только встроенная браузерная (подчёркивает ошибки, но не исправляет).
- **Синтаксис Fountain** — редактор не форматирует текст автоматически, только предлагает кнопки-вставки. Это сознательное решение: редактор не меняет твой текст, ты сам решаешь, как писать.

## 🧠 Техническая архитектура (очень кратко)

| Компонент | Что используется |
|-----------|------------------|
| Хранилище | `localStorage` (проекты, тема, настройки интерфейса) |
| Фронтенд | Чистый HTML + CSS (без фреймворков) |
| Логика | Нативный JavaScript (IIFE) |
| Шрифты | Inter (интерфейс), Courier Prime (текст), Playfair Display / Lora (для HTML-экспорта) |
| Адаптивность | Media queries под 4 размера экрана |
| Кросс-браузерность | Работает везде, где есть современный браузер, но **экспорт в PDF/HTML стабилен только в Chrome** |

## 🎮 Горячие клавиши (шпаргалка)

| Комбинация | Действие |
|------------|----------|
| `Ctrl+S` | Сохранить проект (автосохранение и так работает, но можно вручную) |
| `Ctrl+E` | Экспорт в выбранном формате |
| `Ctrl+T` | Циклическое переключение тем |
| `Ctrl+F` | Включить/выключить фокус-режим |
| `Ctrl+H` | Открыть поиск/замену |
| `Ctrl+Z` / `Ctrl+Y` | Отмена / повтор |
| `Ctrl+1` | Вставить `НАР.` (локация) |
| `Ctrl+2` | Вставить `ИНТ.` (интерьер) |
| `Ctrl+3` | Вставить `ЭКСТ.` (экстерьер) |
| `Ctrl+4` | Вставить `ПЕРС.` (имя персонажа) |
| `Ctrl+5` | Вставить `ДИАЛ.` (диалог) |
| `Ctrl+6` | Вставить `РЕМ.` (ремарка) |
| `Ctrl+7` | Вставить `СЦЕНА #` (автонумерация сцен) |

## 🚀 Быстрый старт

1. Скачай или склонируй репозиторий.
2. Открой файл `index.html` в браузере (рекомендуется **Google Chrome**).
3. Начинай писать сценарий — автосохранение уже работает.

> **Совет:** Используй фокус-режим (`Ctrl+F`), чтобы ничто не отвлекало.
